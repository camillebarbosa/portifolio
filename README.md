# Portifólio Camille Barbosa

## Descrição

Este repositório contém o código-fonte do meu portifólio desenvolvido com HTML e CSS, com funcionalidades adicionais implementadas via JavaScript.

https://camillebarbosa.github.io/portifolio/

## Tecnologias Utilizadas

- **HTML**: Estrutura básica do site.
- **CSS**: Estilização visual e responsiva.
- **JavaScript**: Interatividade para carrinho de compras e ações de navegação.
- **Google Fonts**: Para fontes personalizadas.
- **SVG Icons**: Ícones vetoriais para uma interface limpa.
